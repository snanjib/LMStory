# 导演模式 · 运行机制术语字典

> **用途**：统一导演模式（advanced，产品名「导演模式」）运行机制相关概念的命名与定义。
>
> **范围**：导演会话的执行模型、项目规则、模型与预算、技能、子代理等运行机制范畴。人机协作概念（请示/审批/监督）见 [人机协作](人机协作.md)，过程展示与事件日志见 [过程与事件](过程与事件.md)。
>
> **状态**：初版（2026-08-19 建立，随 v0.3.0 实现）。
>
> **维护原则**：记录曾用名、同步更新；当前可执行代码、数据库 Schema 和匹配当前 API 的测试优先，字典与实现冲突时修订字典。

## 一、模式与角色概念

| 术语 | 英文/代码名 | 定义 | 备注 |
|---|---|---|---|
| 导演模式 | advanced / ChatMode.advanced | 第三种产品模式：AI 作为幕后执行者（「AI 总编辑」）自主检索记忆、撰写正文并维护设定，正文是唯一成果 | 实验性：设置页开关（v0.4.0 起默认开启，可关闭），开启后首页出现「新导演」入口；曾用设想名「高级模式」已弃用 |
| AI 总编辑 | —（产品文案角色名） | 导演模式中 AI 的角色比喻：幕后编排者而非台前角色 | 空态引导、设置页描述使用；与「故事模式」中 AI 直接回应相对 |
| 导演会话 | mode == 'advanced' 的 ChatSession | 走导演内核（AgentRunner）的会话 | 复用 chat_sessions 表，附加 maxSteps/storyAnchor/watchMode 三列 |
| 导演内核 | lib/features/advanced/ | AgentRunner + 工具集 + 技能 + 事件日志 + 提示词组成的执行内核 | 2026-08-18 解耦后编排/UI/状态归位 advanced；曾寄生于 intermediate（历史） |
| 共享运行时 | lib/features/story_runtime/ | 故事与导演两模式共用的运行时（持久化事务、压缩、失败分类、重试、标题生成等） | 两模式同用一套记忆与落库管线 |

## 二、规则与模型概念

| 术语 | 英文/代码名 | 定义 | 备注 |
|---|---|---|---|
| 项目规则 | agent_system_prompt（载体） | 常驻背景规则：世界观、人设、文风与叙事守则；整场会话生效，AI 不会改写 | 等价于「系统提示词当项目规则」的方向纠偏决策；设置入口在导演会话右上角设置；支持从模板直选 |
| 导演主模型 | advanced settings → sectionModel | 导演自主执行所用的模型；未单独配置时跟随全局「生成」模型 | 2026-09-01：GM 内部代号已从用户界面清退；i18n key `advanced.settings.sectionModel(Desc)` |
| 剧情节奏 | advanced.narrative_pacing + 会话列 | 叙事推进档位（保守/平衡/激进），控制每轮正文的"景别" | 2026-08-31 上线；全局设默认、会话内可临时换档 |
| 工具权限 | chat_sessions.tool_permissions | 每个工具的三态开关（允许/询问/禁用），监督模式预设为一键组合 | 2026-08-27 上线；禁用的工具对导演不可见；2026-09-04 起「提交本轮（finish_round）」锁定为允许不可禁用 |
| 轮预算 | advanced.budget + 会话列 max_duration_minutes | 每轮步数与时间上限；步数到顶软着陆（先收尾再停） | 会话级时间预算 2026-08-29 接线 |
| 上下文用量 | advanced.contextBudget + 环形指示器 | 输入区环形指示器（满刻度=上下文压缩阈值）+详情面板+手动压缩 | 2026-09-01 上线；「本会话累计」口径已删除 |
| 轮时间线 | intermediate_round_artifacts.agent_timeline | 每轮幕后过程（思考/播报/动作）按真实顺序存档回放 | 2026-08-28 上线（对话流计划 §4） |
| 导演系统提示词 | agent_system_prompt.dart | 由项目规则 + 技能目录 + 常驻技能等组装的冻结 system 前缀 | 稳定前缀优先以提升 prompt cache 命中 |

## 三、预算与停止概念

| 术语 | 英文/代码名 | 定义 | 备注 |
|---|---|---|---|
| 上下文压缩阈值 | advanced.contextBudget.compactionTriggerRatio（+会话列 override） | 导演模式上下文的唯一用户旋钮：历史占用到达生效窗口（min(模型窗口, 窗口上限)）的这一比例时，下一轮开始前自动压缩历史。百分比⇄token 双显示（token 可直接输入反推百分比）；窗口上限在高级子折叠（0=自动=用模型窗口），是分母修正器非日常旋钮 | 2026-09-13 上下文配置收敛：原「压缩触发线」+「原文区下限」+「检索区比例」三键暴露面收敛为单旋钮；故事三段式遗产两键组装侧定死（检索预留 0、下限动态），键从 advanced 段摘除。与另两道线的关系：①轮中 85% 保命线（agent_runner 硬编码，阈值上限 0.80 恒小于它）——轮内历史没法中途压缩，到线强制收尾；②单轮累计消耗成本线（advanced.budget.token_budget_ratio，默认 0.6）——"花了多少"的计费口径而非"装了多少"，引擎级高级覆盖入口，不占设置面 |
| 步数 / maxSteps | ChatSession.maxSteps | 每轮允许导演自主执行的最大步数（模型请求次数） | 设置项「每轮 N 步」；0 = 无上限（2026-08-17 起），无上限时仍受时间与 token 预算保护 |
| 软着陆 | maxSteps 软着陆（体验重构 C） | 到步数上限不硬停：先注入收尾指令，让导演用现有素材落幕后才停 | 避免正文戛然而止 |
| 收尾指令 | 软着陆注入的指令 | 提示模型用已有素材结束本轮 | 内部机制，用户不直接可见 |
| 落幕 | finish_round | 一轮导演执行的终结工具/舞台动词 | 见过程与事件分册 |
| 死循环检测 | doom_loop_detector | 检测重复无进展的工具调用序列并纠偏 | 内部机制 |

## 四、技能概念

| 术语 | 英文/代码名 | 定义 | 备注 |
|---|---|---|---|
| 技能 / 手记 | AgentSkill（assets/skills/*/SKILL.md） | 渐进披露的写作方法论条目；产品语言用「手记」（舞台动词「翻阅手记」） | 内置 6 个：combat-scenes、deai-flavor、dialogue-scenes、suspense-pacing、tabletop-gm、worldbook-style |
| 技能三层 | 目录层 / 正文层 / 常驻层 | ① frontmatter 目录摘要常驻（<100 token/skill）；② 正文按需由 read_skill 读入；③ `alwaysInject` 技能的 `<!--resident-->` 精编正文（≤500 token）并入冻结 system 前缀 | 常驻层等价「CLAUDE.md 压缩后重注入」机制 |
| 技能装载器 | asset_skill_loader | 从 assets 装载 SKILL.md 的 loader | 由 DirectorRoundRunner 接线 |
| 技能目录摘要 | catalogDigest | 任一 skill 增删改即变化的目录摘要 | 目录作为 durable 消息注入会话，digest 变更才全量替换 |

## 五、子代理概念

| 术语 | 英文/代码名 | 定义 | 备注 |
|---|---|---|---|
| 子代理 | agent_subagent / spawn | 导演可派出的辅助执行体，独立完成局部任务后汇报 | 舞台动词「派出子代理」；自主性重构引入 |
| 同任务书防重 | SubagentBriefMemo | 会话级单槽记忆：同 brief 二次派发直接回执上次结论不真跑（2026-09-04 引入） | 防 spawn 豁免 doom 检测下的同任务书反复白跑；不同 brief 正常派发 |
