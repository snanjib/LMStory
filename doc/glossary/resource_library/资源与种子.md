# 资源库 · 世界书与角色卡术语字典

> **用途**：统一世界书/角色卡资源（resource_library feature）相关概念的命名与定义。
>
> **范围**：资源库、导入、应用、投影、只读种子等概念（DOC-15）。记忆系统本体见 [故事模式·记忆系统](../intermediate/记忆系统.md)。
>
> **状态**：初版（2026-08-19 建立，随 DOC-15 实施完成）。
>
> **维护原则**：记录曾用名、同步更新；代码与 Schema 优先。

## 一、资源概念

| 术语 | 英文/代码名 | 定义 | 备注 |
|---|---|---|---|
| 资源库 | resource_library | 存放导入的角色卡与世界书的全局仓库（设置 → 角色卡/世界书） | feature 目录 lib/features/resource_library/；应用内 Wiki 术语表同义 |
| 世界书 | worldbook / Worldbook | 提前写好的设定词条集合（如货币规则、地理、魔法体系），只读资源 | 项目定位表述：「种子，不是门票」 |
| 角色卡 | character card / CharacterCard | 预设角色的卡面资产（人设、性格、开场等），只读资源 | 支持 SillyTavern 兼容格式 |
| 只读资源 | readonly resource | 导入后的资源实体：**基线行**不可编辑、不可删除（会话内），不写审计历史；实体本身可生长（新增属性/别名/归档落 auto 行） | 只读语义 2.0（2026-09-14）：世界书与角色卡同为属性级只读基线 |
| 只读基线 | readonly baseline（source != auto） | 导入实体（世界书/角色卡）的基线属性行：永不改写、不可移除；主名亦属基线（改名意图转别名，旧主名保留） | 只读语义 2.0（2026-09-14）新增词条 |
| 演变行 | evolved row（source=auto） | 与基线同键并存的 source=auto 属性行：承载剧情变化；注入时与基线聚合为「原内容（初始）；新内容（演变）」 | 记忆库属性行有「基线/演变」行级徽标 |
| 种子 | seed（产品比喻） | 资源应用到会话后的角色：是世界起点的一部分，不决定世界如何生长 | 对外措辞以 doc/product/00_项目定位.md 为准 |

## 二、导入概念

| 术语 | 英文/代码名 | 定义 | 备注 |
|---|---|---|---|
| 导入 | resource_import_service | 将外部文件解析入库的动作 | 入口：资源库页面 + 外部「打开方式/分享」（Android VIEW intent） |
| PNG 角色卡 | character_card_parser.extractCardJson | 从 PNG `tEXt` chunk 提取 V1/V2（`chara`）/ V3（`ccv3`）base64 JSON，V3 优先 | 参照 SillyTavern `extractDataFromPng` 算法 |
| 纯 JSON 角色卡 | importCardJson | 不带 PNG 壳的 V2/V3 角色 JSON | 顶层 spec/data 标记判别；V1 至少有 name |
| 世界书 JSON | worldbook_parser | 顶层 `entries` 结构的世界书导出文件 | entries 为字典（独立导出形态） |
| CHARX | —（不支持） | SillyTavern 新封装格式 | 当前不支持，规划项；对外声明不得写成已支持 |
| 导入体积上限 | import size limit | 防 PNG tEXt base64 膨胀的上限 | DOC-15 §5.1 |

## 三、应用与投影概念

| 术语 | 英文/代码名 | 定义 | 备注 |
|---|---|---|---|
| 应用（到会话） | resource_apply_service | 将资源绑定到某个故事会话的动作 | 入口：故事会话设置 → 角色卡/世界书区段 |
| 投影 | resource_projection_service | 将资源内容写入会话内事实层的过程：角色卡字段→character 实体、世界书词条→lore 实体 | 投影实体带 source/sourceRef，标记来源 |
| 投影实体 | source 标记的 factual entity | 资源投影产生的事实实体：基线属性（source=worldbook/card）作基线注入、不写 factual_memory_history；演变属性（source=auto）有审计历史 | 只读语义 2.0（2026-09-14）：与 AI 运行中学得的事实按行级 source 区分，可并存同键双行 |
| 同名拒绝 | 应用时的去重约束 | 会话内已有同名实体时拒绝应用并提示 | 避免重复/覆盖 |
| 强制注入 | forceInject（列，v37） | 对实体勾选后每轮必注入上下文（不参与检索评分） | v0.2.3 实体强制注入开关；记忆库批量 UI 可设置 |

## 四、与记忆层的关系

| 概念 | 说明 |
|---|---|
| 静态基线（资源） vs 动态事实（记忆） | 资源投影是「作者设定」的基线；AI 在运行中修订/新增的事实走正常事实层（带历史、可被监督模式把关）。两层在检索时共同参与。只读语义 2.0（2026-09-14）后两层同键并存：基线行 + 演变行（auto），注入时聚合展示 |
| 记忆库中的只读提示 | 世界书/角色卡投影实体的基线行不可编辑/删除（属性行带「基线/演变」徽标）；实体可新增属性（落 auto 演变行）与归档（状态标记非删除） |

## AI 建卡（2026-09-11，2026-09-12 完善）

| 术语 | 定义 |
|---|---|
| AI 建卡（resource_ai） | 与 agent 对话生成/编辑角色卡与世界书的工具 feature。agent 经 update_draft/finalize_draft/read_skill 三工具逐字段写草稿，用户在会话设置面板实时预览、完成创建后落库。 |
| 草稿（Draft） | 会话内不可变值对象（CardDraft/WorldbookDraft），所有变换返回新实例；未经确认不落库。 |
| 会话级设置（2026-09-12） | 建卡对话的 AppBar ⚙ 面板：模型（选中即持久化 override，下一轮生效）、温度/单轮最大步数（释放提交）、实时草稿预览、完成创建入口。重置=快照当前全局值（snapshot-first，无「跟随全局」动态引用）。 |
| 完成创建（2026-09-12） | 结束写卡的确认流：新建=保存到资源库；编辑=另存或覆盖更新原资源。成功后会话自动退出（toast 提示），资源库列表刷新，落库资源可在故事/导演模式应用。 |
| 过程线（2026-09-12） | 聊天流中工具改稿的差分摘要行（「更新了性格」「添加词条『xx』」等，本地化），与预览字段标签同源。 |
| 覆盖保存（patch 语义） | 编辑目标的原文留底 → 深拷贝后只覆盖草稿触达的键，未知字段（extensions/character_book 等）原样保留。 |
| 另存 | 不论编辑与否都以新建路径落库（新 id），不动原资源。 |
| 模型首用快照 | resource_ai 模型引用无静态默认；首次进入工具页把全局默认对话模型（broadcast_chat）写入 override 快照，之后静态。 |
