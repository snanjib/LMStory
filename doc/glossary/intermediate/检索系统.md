# 故事模式 · 检索系统术语字典

> **用途**：统一故事模式（Intermediate mode）检索系统相关概念的命名与定义，消除代码与文档中的术语歧义。
>
> **范围**：多通道检索、关键词分类、检索评分、注入内容等检索系统范畴的概念。空间分配见 [上下文工程术语字典](上下文工程.md)，阶段流程见 [生成流程术语字典](生成流程.md)。
>
> **状态**：初版，从 [上下文工程.md](上下文工程.md) 第五章移入并扩展。
>
> **维护原则**：
> - **记录曾用名**：术语变更时在备注中记录旧称
> - **同步更新**：每次术语调整须同步更新本字典并在变更记录中登记
> - **权威顺序**：当前可执行代码、数据库 Schema 和匹配当前 API 的测试优先；本字典负责记录统一术语，若与代码事实冲突必须修订本字典

## 一、检索方式概念

| 术语 | 英文/代码名 | 定义 | 备注 |
|---|---|---|---|
| 多通道检索 | searchExperiencesMultiChannel | 5 路并行混合检索（3 FTS5 + 2 Vector） | v0.2.2 引入，替代旧的两路混合检索 |
| 关键词检索 | fts5Search | 基于 FTS5 的全文检索 | 实体类关键词（角色/物品/地点）的固定通道，与 Vector 并行非降级 |
| 语义检索 | semanticSearch | 基于 embedding 的向量检索 | 事件类关键词（动作/情节）的固定通道；embedding 未配置时该通道降级为空 |
| 混合检索 | - | FTS5 + Vector 并行检索的统称 | 各通道独立评分，非降级关系 |

## 二、关键词分类概念

| 术语 | 英文/代码名 | 定义 | 备注 |
|---|---|---|---|
| 关键词分类 | classifiedKeywords | extracting 阶段提取的 5 类关键词 | characters/items/locations/actions/plots |
| 实体类关键词 | characters / items / locations | 角色名 / 物品名 / 地点名 | FTS5 固定通道检索 |
| 事件类关键词 | actions / plots | 动作 / 情节 | Vector 固定通道检索 |

## 三、检索评分概念

| 术语 | 英文/代码名 | 定义 | 备注 |
|---|---|---|---|
| 综合评分 | finalScore | 检索结果的最终评分 | FTS5 与 Vector 加权合并后，按阈值应用 keyEventBoost，再叠加 recency 加分，最后乘以 importance 系数；低相关结果可先被质量阈值过滤 |
| 时间衰减 | - | 越早的记忆评分越低 | 基于 turnNumber 差值计算 |
| 关键实体强制注入 | keyEntityInjection | importance >= 阈值的关键实体无视检索分数注入 | 默认阈值 5，最多 3 个；仅主角级实体每轮强制注入，避免低优先级实体挤占上下文 |

## 四、注入内容概念

| 术语 | 英文/代码名 | 定义 | 备注 |
|---|---|---|---|
| 事实层注入 | factBlock | 角色属性、世界设定的结构化注入块 | DOC-11 §6.3；【世界设定】块；system 角色注入 |
| 往事注入 | memoriesInjection | 检索到的历史经历事件注入块 | 【相关往事】块；system 角色注入 |
| 检索区比例 | retrievalRatio | 为事实与经历记忆预留的比例 | 默认 0.15；当前实现存在两种基准：ContextBuilder 以 `availableWindow = contextWindow - maxTokens` 计算实际组装预算，CompactionService 以 `contextWindow` 估算压缩前检索预留；这是待统一的代码口径，不应写成单一分母 |

> 检索注入区占用的空间见 [上下文工程.md](上下文工程.md) 第二章「检索注入区」。
