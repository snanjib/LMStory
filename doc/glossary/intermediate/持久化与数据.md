# 故事模式 · 持久化与数据术语字典

> **用途**：统一故事模式（Intermediate mode）持久化与数据相关概念的命名与定义。
>
> **范围**：数据库表结构、持久化时序、数据关联等持久化范畴的概念。阶段产物见 [生成流程术语字典](生成流程.md)，记忆表结构见 [记忆系统术语字典](记忆系统.md)。
>
> **状态**：初版。
>
> **维护原则**：记录曾用名、同步更新；当前可执行代码、数据库 Schema 和匹配当前 API 的测试优先，字典与实现冲突时修订字典。

## 一、数据表概念

| 术语 | 英文/代码名 | 定义 | 备注 |
|---|---|---|---|
| 轮次产物表 | intermediate_round_artifacts | 持久化每轮生成产物的快照表 | v0.2 新增；通过 sessionId + turnNumber 关联 ChatMessage |
| 压缩点表 | compaction_points | 记录压缩操作的持久化标记表 | summaryMessageId <-> boundaryMessageId 映射 |
| 经历记忆表 | experiential_memories | 事件记忆表 | 详见 [记忆系统.md](记忆系统.md) |
| 事实层三表 | factual_entities / factual_attributes / factual_memory_history | 事实层中间方案的三张表 | 详见 [记忆系统.md](记忆系统.md) |
| 会话表 | chat_sessions | 故事模式会话表 | mode=intermediate；含会话级覆盖字段 |

## 二、持久化时序概念

| 术语 | 英文/代码名 | 定义 | 备注 |
|---|---|---|---|
| 整轮事务性 | - | 持久化阶段的消息、经历记忆、索引、轮次产物和压缩点等在同一事务中提交 | 每条事实变更经独立保存点写入事实、关联索引和流水。失败时回退该条并记录日志，继续处理其余条目 |
| 覆盖前快照 | Pre-overwrite snapshot | 覆盖导入涉及已有数据时保存的备份，可在数据管理中恢复 | 原生存入备份目录，Web 存入当前浏览器。快照排除 API Key |
| 启动恢复 | Startup recovery | 开库失败后从启动界面选择备份并查看检查结果 | 原生支持在独立数据库试恢复后确认切换。Web 支持格式和版本检查 |
| 持久化时序 | - | persisting 阶段在单一 drift transaction 中编排最终写入 | 包含 chat_messages、intermediate_round_artifacts、experiential_memories、memories_fts/embedding、事实层 deltas、叙事时间，以及本轮触发时的 compaction_points 与分段宏摘要；具体顺序以 IntermediatePersistenceService 实现为准 |
| 重新生成时序 | - | 重新生成场景的持久化逻辑 | 复用原 turnNumber，覆盖旧产物 |
| 串行约束 | - | 单会话同一时间只允许一个生成流程 | generating -> ... -> idle 或 failed |

## 三、数据关联概念

| 术语 | 英文/代码名 | 定义 | 备注 |
|---|---|---|---|
| 轮次编号 | turnNumber | 轮次序号 | ChatMessage / intermediate_round_artifacts / experiential_memories 三表对齐 |
| 审查执行标记 | reviewExecuted | 记录本轮是否执行了审查阶段 | artifacts 字段；曾用名 reviseExecuted；详见 [生成流程.md](生成流程.md) |
| 会话级覆盖 | override | 会话级配置覆盖全局默认 | 多数字段以 null 表示使用全局；当前会话实体还包含生成参数、上下文限制、JSON/工具调用、推荐回复、审查与预算等覆盖，字段全集以 ChatSession 实体为准 |
| 分步骤模型 | SessionPhaseModels | 各阶段独立配置的供应商 + 模型 | 4 阶段 × 2 字段；详见 [生成流程.md](生成流程.md) 配置术语 |
