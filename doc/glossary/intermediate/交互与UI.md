# 故事模式 · 交互与UI术语字典

> **用途**：统一故事模式（Intermediate mode）交互与 UI 相关概念的命名与定义。
>
> **范围**：面板组件、流程时间线、流式显示、输入框状态、视觉主题等交互与 UI 范畴的概念。视觉规范详见 `doc/design/06B_中级模式视觉规范.md`。
>
> **状态**：初版。
>
> **维护原则**：记录曾用名、同步更新；当前可执行代码、数据库 Schema 和匹配当前 API 的测试优先，字典与实现冲突时修订字典。

## 一、面板组件概念

| 术语 | 英文/代码名 | 定义 | 备注 |
|---|---|---|---|
| **生成面板** | **GeneratePanel** | **生成阶段**的折叠小窗 | **曾用名「草稿小窗」(DraftPanel)**；仅审查开启时显示；显示生成流式内容 |
| 提取面板 | ExtractPanel | 关键词提取阶段的折叠小窗 | 显示 5 类关键词 |
| 检索面板 | RetrievalPanel | 检索阶段的折叠小窗 | 显示检索结果 + 事实层命中 |
| 摘要面板 | SummarizePanel | 摘要阶段的折叠小窗 | 显示事件摘要 |
| ~~宏摘要面板~~ | ~~MacroSummaryPanel~~ | 已废弃的独立宏摘要阶段面板概念 | 当前没有独立宏摘要阶段或 MacroSummaryPanel；分段宏摘要由压缩流程后台生成，不增加独立流程面板 |
| 失败栏 | FailureBar | 失败提示栏 | 所有失败阶段都显示 |
| 回复气泡 | IntermediateMessageBubble | 故事模式的消息气泡 | 审查开启时显示审查流式内容；审查关闭时直接显示生成流式内容（此时不显示生成面板） |
| 轮次小窗 | - | 泛指各阶段的折叠小窗 | 统称：生成面板/提取面板/检索面板/摘要面板 |
| 稿件变体 | MessageVariant | 重生成/编辑重发时旧稿自动快照存档，稿件卡 ◀ n/m ▶ 切换器可查看/复制/切换/删除，切换即改变后续走向 | 2026-09-16 落地（此前重生成直接覆盖旧稿）；存储= message_variants 表 + artifacts.current_variant_index 指针 |

## 二、流程可视化概念

| 术语 | 英文/代码名 | 定义 | 备注 |
|---|---|---|---|
| 流程时间线示意图 | VisualFlowTimeline | 帮助中心用于讲解阶段顺序的静态/说明性组件 | 当前仅位于 `features/help`，不是故事聊天页的运行时进度组件；聊天页通过各阶段面板呈现进度 |
| 生成节点 | - | 帮助中心时间线示意中的生成阶段节点 | 说明审查关闭时“生成即最终”、开启时继续进入审查；不是独立运行时 Widget |
| 审查节点 | - | 帮助中心时间线示意中的可选审查节点 | 根据讲解场景展示；实际执行由 reviewEnabled 决定 |

## 三、流式显示概念

| 术语 | 英文/代码名 | 定义 | 备注 |
|---|---|---|---|
| 生成流式显示 | - | 生成阶段的流式文本展示 | 审查开启时显示在生成面板；关闭时直接显示在回复气泡（不显示生成面板） |
| 审查流式显示 | - | 审查阶段的流式文本展示 | 显示在回复气泡（主区域） |
| 面板折叠 | - | 阶段完成后小窗折叠为摘要 | 如"第 N 轮 · 生成完成" |
| 面板展开 | - | 点击折叠小窗展开查看完整内容 | 查看历史轮次的生成正文等 |

> 流式内容字段定义见 [生成流程.md](生成流程.md) 流式显示术语。

## 四、输入框状态概念

| 术语 | 英文/代码名 | 定义 | 备注 |
|---|---|---|---|
| 生成中状态 | - | generating 等阶段进行中时输入框的状态 | 显示停止按钮，禁止发送 |
| 失败状态 | - | failed 状态时输入框的状态 | 显示重试选项 |
| 推荐回复 | suggestReply | AI 推荐的下一步回复选项 | 独立于生成流程的额外 LLM 调用 |

## 五、视觉主题概念

| 术语 | 英文/代码名 | 定义 | 备注 |
|---|---|---|---|
| 夜航配色 | night-voyage-* | 曾为「故事模式专属视觉主题」；现为 Classic 配色族夜间档的取值锚（bg #0E1018 / primary #D4A042），不再是独立主题，也不是故事模式私有 | 06B 视觉规范；外观体系已迁双轴（结构×配色） |
| 进入转场 | - | 从对话模式切换到故事模式的动画 | 仪式感动效 |
| 仪式感动效 | - | 故事模式独有的动画风格 | 生成/检索/回复的呈现有仪式感 |

## 六、消息操作概念

| 术语 | 英文/代码名 | 定义 | 备注 |
|---|---|---|---|
| 消息操作菜单 | MessageActions | 消息气泡点击后显示的操作按钮行 | 两种消息统一显示 4 个按钮：复制、重新生成、编辑、删除整轮 |
| 编辑对话框 | IntermediateEditDialog | 编辑消息内容的弹窗 | 双模式：allowResend=true 显示"保存"+"保存并发送"；allowResend=false 只显示"保存" |
| 保存 | save | 仅更新消息文本，不重新生成 | 不清理记忆，适用于小修改 |
| 保存并发送 | saveAndResend | 修改文本后删除下游消息并重新生成 | 有事务保证清理旧记忆 |
