# 故事模式 · 记忆系统术语字典

> **用途**：统一故事模式（Intermediate mode）记忆系统相关概念的命名与定义。
>
> **范围**：经历记忆、事实层中间方案（DOC-11）、事件摘要结构、向量化、叙事时间等记忆系统范畴的概念。阶段产物见 [生成流程术语字典](生成流程.md)，压缩摘要见 [上下文工程术语字典](上下文工程.md)。
>
> **状态**：初版。
>
> **维护原则**：记录曾用名、同步更新；当前可执行代码、数据库 Schema 和匹配当前 API 的测试优先，字典与实现冲突时修订字典。

## 一、经历记忆概念

| 术语 | 英文/代码名 | 定义 | 备注 |
|---|---|---|---|
| 经历记忆 | experiential_memories | 以追加新事件为主的经历记忆表 | 每条含 turn_number + narrative_time + memory_level；并非严格 append-only：重生/编辑重发、记忆合并和会话清理可删除记录，向量重建会更新 embedding |
| 记忆层级 | memory_level | 事件粒度分级 | 当前仅 micro / macro 两级；micro 为单轮事件记忆，macro 为分段摘要 |
| 父事件关联 | parent_event_ids | 事件之间的关联引用 | 用于宏事件包含子事件的关系 |
| 宏触发原因 | macro_trigger_reason | 标记宏摘要的触发来源 | 当前生产路径使用 `compaction`；枚举/数据库兼容值另保留 `event_end`、`round_limit`，不得误写为 EventSummary 字段名 `event_ended` |

## 二、事件摘要结构概念

| 术语 | 英文/代码名 | 定义 | 备注 |
|---|---|---|---|
| 事件摘要 | eventSummary | 每轮生成的事件摘要（5W1E 格式） | 生成流程产物，写入 experiential_memories；曾用名「微摘要」；详见 [生成流程.md](生成流程.md) |
| 5W1E 六字段 | when/where/who/what/significance/extra | 事件摘要的结构化字段 | v20 新增；when_text/where_text/who_text/what_text/significance/extra |
| 叙事时间 | narrative_time / current_narrative_time | 故事内的叙事时间 | 从 chat_sessions.current_narrative_time 读取；summarizing 阶段注入提示词 |
| 叙事周期 | narrative_period | 预留的事件分组字段 | v0.3 计划项；当前生产写入恒为 null，尚未实现按叙事周期分组 |
| 轮次编号 | turnNumber | 事件对应的轮次序号 | 与 ChatMessage.turnNumber 对齐 |

## 三、事实层中间方案概念（DOC-11）

| 术语 | 英文/代码名 | 定义 | 备注 |
|---|---|---|---|
| 事实层中间方案 | - | v0.2 事实层的简化实现 | 核心数据为 entity + attribute 双表，另有 factual_memory_history 审计表，实际共三表 |
| 事实实体 | factual_entities | 角色名 / 地点名等结构化实体 | 每个实体有唯一 entityId |
| 事实属性 | factual_attributes | 实体的属性键值对 | 事实详情、变更详情和记忆库按界面语言显示内置属性标签，自定义键及关系对象名保留原文 |
| 按对象关系属性 | relationship:对方名 | 与某个具体角色的关系属性（single） | 2026-11-08 起：每个对象一条、update 维护完整当前描述（有方向，不推断对称）；对象别名唯一命中时键归一到正式主名；迁移自旧 relationships 字典的个人关系条目保留审计来源 |
| 群体关系属性 | relationships | 群体/笼统关系的字典属性（dict） | 仅整体 update（如「与师门众人交恶」）；append 被程序拒绝（旧缺陷：单条追加会整体覆盖字典内容，已修复并迁移存量） |
| 事实历史 | factual_memory_history | 事实变更的审计日志 | 记录每次属性变更的前后值 |
| 事实变更 | FactsDelta | summarizing 阶段产出的事实变更 | 工具调用返回；单条写入失败独立回退，故事和导演模式在成功收稿后提示失败数量，跳过及无失败不提示。详见 [生成流程.md](生成流程.md) |
| 事实变更记录 | FactsChangeRecord | FactsDelta 与审计记录合成的 UI 视图 | 携带实体名/类型/属性名（来自 delta）+ 变更前/后（来自 factual_memory_history）；持久化到 intermediate_round_artifacts.facts_changes，供「事实层变更小窗」展示 |
| 事实层变更小窗 | FactsChangePanel | 展示本轮事实层变更的小窗 | 位于摘要小窗之后；无变更时显示「本轮无事实变更」占位；点击单条弹 FactsChangeDetailDialog 查看变更前/后 |
| 三级保护 | - | 事实层的保护机制 | 防误删 / 防覆盖 / 防冲突 |
| 五层健康守卫 | - | 事实层写入前的健康检查 | 确保数据一致性 |

## 四、向量化概念

| 术语 | 英文/代码名 | 定义 | 备注 |
|---|---|---|---|
| 向量化 | vectorization | 将事件摘要转为 embedding 向量 | 用于语义检索 |
| 两级向量化策略 | - | 按 importance 阈值分级向量化 | 高重要性事件优先向量化；低重要性可选跳过 |
| 存储索引门槛 | importance_storage_threshold | importance 低于此值的记忆不建索引 | 默认 3；可在「工具与记忆」设置调整；纳入低分记忆需调低 |
| 向量化门槛 | micro_vectorize_threshold | 达到此值的记忆才生成 embedding | 默认 4；介于两门槛之间仅建 FTS5；可在「工具与记忆」设置调整 |
| 宏摘要向量化 | macroEmbedding | 压缩落库路径对前情摘要宏记忆同事务写入 embedding | 四条路径覆盖（普通轮/重生成轮/手动压缩/记忆合并对照）；嵌入未配置或失败降级 has_embedding=false 仅 FTS 兜底，不阻断压缩；宏 importance=3 低于门槛，不入「重建向量索引」清单 |
| 向量维度 | embedding_dimensions | 记忆行记录向量维度（LENGTH(blob)/4），schema v50 新增 | 换嵌入模型后按会话最近写入维度判定陈旧行，「与新模型不匹配」可一键重建 |
| 向量引擎 | VectorEngine | 纯 Dart 暴力余弦相似度检索 | batchSearch + Isolate；sqlite-vec 已弃用 |

## 归档让名 / 找相似（2026-09-02 起）

- **归档让名**：实体主名唯一索引只约束活跃行（partial，WHERE is_archived=0）——归档实体释放主名，世界书词条/角色卡撞归档名可正常创建；撞活跃名仍拒绝/跳过。
- **找相似**：记忆库事实 Tab 的聚类入口——活跃实体按「名称互为包含（短名 ≥2 字）」聚成组，一键预选进多选归并。
- **疑似重复**：本轮 create_entity 的名称与既有实体互为包含时，事实变更小窗显示「疑似重复」行，点击直达记忆库并预选候选归并。
- **归并口径**（唯一真源：导演 merge_entities）：世界书实体两角色皆不可；角色卡不能被吸收、只能作保留者。归档审计行轮号 = 当前会话最大轮+1（重生成回滚不复活被吸收实体）。

## 归档默认隐藏（2026-09-03 起）

- **默认只显示活跃实体**：记忆库事实 Tab 归档筛选初始为「活跃」——归并/ARCHIVE_ENTITY 后的归档实体不再混在列表里；统计栏默认如实显示"显示 X / N"。筛选栏三态可切：「全部」（含归档）/「活跃」（默认）/「已归档」（只看归档）。
