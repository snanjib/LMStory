# 前端组件接口层：实现约定

> 当前代码约定。运行行为以 `lib/core/theme/` 为准。

## 装配边界

`ThemeCatalog` 按结构、配色族、明暗档装配 `ThemeData`，并把该结构的 `LmComponentKit` 注入 `LmComponents` 扩展。配色族提供语义色槽，结构实现只消费色槽，不拥有业务状态。持久化结构 ID 为 `classic`、`glass`、`brutal`、`wonder`；显示名为经典、琉璃、印刻、漫游。

业务页面通过 `context.lmUi` 请求卡片、设置入口、首页入口、会话行、选择行、消息气泡、输入区和浮层等界面职责。`context.lmVenue` 与 `context.scaffoldBgOf` 处理路由场地。新增结构时实现 `LmStructure` 和 `LmComponentKit`，再在 `ThemeCatalog.structures` 登记，不在业务页面判断结构 ID。

自绘小件通过 `context.lmUi.radius(LmCorner.*)` 获取几何档位。经典与琉璃沿用原档位，印刻使用直角，漫游按阅读层级放大卡片圆角。Material 控件的字体、按钮、表单、对话框、导航、Chip 等由各结构的 `ThemeData` 配方提供。

## 实现纪律

1. 接口参数表达内容与交互状态，不传领域实体。页面保留会话加载、导航、回调和可访问性语义。
2. 每个注册结构必须提供完整 Kit；带 `LmTokens` 的主题若缺 Kit 即报错。仅使用原生 `ThemeData` 的嵌入宿主回落到经典组件，以兼容既有组件测试与外部挂载。
3. 结构实现不得硬编码配色族身份，也不得增加流式正文区模糊或常驻动画。减弱动态沿用系统设置。
4. 经典与琉璃基线由 `appearance_visual_parity_test.dart` 守卫。印刻／漫游按两配色 × 明暗档验证装配和主要交互。

## 两套新结构的方向

- **印刻**借鉴 Neubrutalism 的明确描边、硬偏移按压和强字重。`brutal` 是兼容 ID，产品名为「印刻」。日间描边与实心阴影取当前配色族的 `ink`，夜间取 `dividerStrong`；文字仍取 `ink`，保留所有三轴组合。
- **漫游**借鉴 Wonderous 的场景层次与叙事入口。LMStory 采用安静的渐变场地、衬线标题与顶部平直、圆角一致的入口卡片，让长篇阅读保持主体地位；`wonder` 是兼容 ID，产品名为「漫游」。

## 动效几何与共享反馈

`LmComponentKit.motionProfile` 提供结构的入场偏移、交互偏移、按压比例、活动点形状和曲线；时间仍取 `LmMotion`。业务只使用结构中立的 `LmArrival`、`LmActivityDots`、`LmStateTransition`、`LmInteractiveMotion`，不判断结构或配色 ID。持续反馈只重绘小层，后台、离屏和减弱动态时停止；离散触发不得包含流式文本增量。
