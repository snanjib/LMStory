# 导演模式请求时限与全过程反馈

更新时间：2026-11-03。当前实现约定；具体供应商失败尚未取得现场日志，不能把单次失败归因为思考过长。

## 请求时限

未知中转站带工具请求保守降级为非流式。供应商生成 token 不等于客户端收到完整结果。旧非流式路径的连接时限实际覆盖响应头等待，读取时限覆盖整个响应体接收，不是空闲续期；导演并无固定的60秒上限。

导演及其子代理使用独立首响应时限（发送到首个响应体数据）和非流式完成时限（发送到完整响应接收），默认均为600秒。流式首数据后使用既有空闲读取时限并随数据续期。非流式总时限不续期。原生连接池按连接时限隔离，Web连接建立由浏览器控制。其他调用者保留兼容计时语义。

长时限耗尽为独立终态错误，不自动重复十分钟请求；普通连接和流式空闲错误沿用重试策略。取消与时限耗尽作用于单请求，中止本地传输、结束等待并拒绝迟到结果；供应商仍可能继续推理。首次响应之前Web不并行运行短空闲计时器。

## 内容与状态

完整响应事件使用请求步号，在步骤计数递增前发送；按每次尝试的实际增量通道回填缺失的思考与文本，流式不重复，重试清空旧尝试。复用现有时间线及artifacts，无数据库迁移。非流式不伪造token流或思考耗时，签名与隐藏块不作明文展示。

当前活动由事件驱动，覆盖等待响应、思考、工具执行、正文生成和响应整理；外围阶段补充本轮准备、上下文整理、保存收尾、重试等待及等待用户。工作摘要不沿用已完成工具。正在运行的标题使用现有流光，工作结束即停；等待用户不表现为模型执行中。减弱动态、后台与TickerMode禁用时停止动画。

## 思考窗口与视觉层次

单个思考默认收起；生成中显示最后三视觉行，按真实排版取尾部，支持中文和字体缩放。整组收起仍只显示当前活跃思考尾部，结束后撤下；其他收起内容全部隐藏。

展开窗口最高为240dp和视口高度40%中的较小值，支持选择复制和独立滚动。位于底部时随新内容跟随，上滚后暂停。新内容和完成状态不覆盖手动展开选择。

思考使用明确标识、紧凑排版和可读次级文字；幕后输出使用单独标识、缩进和间距；正文保留正式叙事排版与最高阅读优先级。次级文字由语义色向主文字色调整，确保页面和阅读表面上至少4.5:1对比度。流光只扫过活动标题，不扫过正文。四结构、两配色及日夜均纳入组件验收。

## 调研依据与交付界限

DeepSeek Harness提供折叠思考实时摘要，OpenCode提供独立思考状态，pi提供逐块显隐和渲染复用；Codex公开工作项生命周期用于参考事件驱动方式。三行尾部与限高阅读窗口为LMStory的明确产品设计，并非上述项目统一采用的模式。

本波为已有生成与过程展示的行为完善；核对功能索引、能力清单及术语表后，不新增工具或产品模式条目。更新应用内过程/失败帮助、变更记录、版本里程碑及探索地图。真实供应商归因与实机长会话体验需单独核对。

## 中间发言实时归位与到达顺序补修

普通assistant文本从首个增量开始进入幕后输出，不依据字数或最后一段的位置判断正文。明确的finish_round.prose流入正文区域，纯文本回退沿用原有终态交付判据，确认后才升格。普通发言使用独立的“正在说明工作”状态，避免将中间说明误报为正文生成。

直播块保留assistant、finishRoundProse、confirmedFallback来源。相同请求内的普通发言与正文分别累计；同一交稿调用以请求步号和toolCallId维持稳定正文身份，参数与普通发言或思考交错时不丢失正文前缀。完整参数只修正对应正文，不覆盖发言。明确正文不进入工作时间线，近拷贝折叠仅作用于普通发言并保留其来源和顺序。

新内容块和工具步骤在首次出现时取得共享单调顺序号，增量、工具进度与完成更新原条目。合帧器保留来源、顺序及工具边界；请求重试清空该尝试的文本和参数提取残段，续跑从已有最大序号之后追加。序号以可选字段保存到现有JSON，历史数组按原顺序读取，旧数据缺少序号时保留旧输入的兼容装配规则，不重写历史。

取消或失败保留已收到的工作内容：未确认文本仍在幕后，明确正文仍在正文区域。已结束一轮不再把中间发言从正文位置搬回幕后。

## Anthropic 中转思考与跨轮计时补修

显示侧按请求增量分离文本中的 `<think>…</think>`，包括跨帧拆开的标签；真实思考进入思考块，标签外文本仍为幕后发言。结构化思考的包装标签仅从可见内容去除；签名、原始 thinkingBlocks 与有序 contentBlocks 不修改。块开始事件自带的文本与思考同时发出可见增量，避免只累积原始块而让直播丢失内容。非流式响应在没有 reasoningContent 时从可读 thinkingBlocks 回填，隐藏思考块与签名不作为显示内容。

旧时间线只含工具卡时，不再隐藏消息中已有的 thinkingContent；没有保存过的历史内容无法凭空恢复，不改写数据库。换轮时清除旧起表偏移、停止旧周期并按新锚点重新起表，避免复用组件继承上轮用时。

回归使用合成 Anthropic SSE 经过真实解析器、网关、导演循环与内存数据库，覆盖原生块与标签思考、下一轮、重新生成和重载。真实 Sonnet 5.5 中转负载及用户长会话尚未直接访问，实机复验仍待完成。

### Sonnet 5.5 思考缺失简查

[Anthropic官方迁移说明](https://platform.claude.com/docs/en/models/sonnet-5-5/migration-guide)明确：Sonnet 5.5默认运行adaptive thinking，但display默认omitted，思考块可只有空文本及signature；显式请求display:summarized才返回可读摘要。本仓自动adaptive形态未主动请求该display字段，符合这种现象；中转站是否按原协议透传仍未核实，不能据此认定反蒸馏。此处仅记录调查，本次不改供应商参数或策略。
