## 1. 背景与问题

故事模式"设置"在使用中暴露四类问题（对话模式对称存在，本轮仅落地故事模式，对话模式列入后续建议）：

1. **上下文预算：两项看起来"灰的不可调"**
   - `检索区比例`（`retrievalRatio`）确为可调。
   - `原文区下限`（`recentMinRatio`）其实可调，但默认值 `null`（"动态"态），组件此时画成灰色固定刻度，需点"动态↔自定义"开关才出现真滑块——属于可发现性问题。
   - `压缩触发线`（`compactionTriggerRatio`）被产品固定为 `0.5`：全局/会话均无编辑入口、无会话覆盖列，`ContextBudgetSlider` 仅以 `_FixedSliderMark` 展示。
2. **思考预算缺"未配置"**：故事模式会话级选择器 `IntermediateReasoningEffortSelector` 仅 4 档（禁用/低/中/高），将 `null` 兜底为 `disabled`；其余 3 个选择器（对话会话、对话全局、故事全局）均已有第 5 项。
3. **滑块易误触 + 数值不可输入**：所有滑块用 Flutter `Slider` 默认行为（点轨道即跳），上下滑动页面时易误改配置；数值仅作 `Text` 展示，无法直接输入。散落 15 个构造点，无统一组件。
4. **会话设置扁平化**：`IntermediateSessionSettingsSheet` 为单一 `SingleChildScrollView → Column`，约 20 项、7~8 个分区，仅靠 `IntermediateSectionHeader`（标题+分割线）分段；无折叠、无单项边界、无状态记忆。

## 2. 关键决策（已与产品确认）

- **上下文预算**：`压缩触发线` 与 `原文区下限` 均改为**全局 + 会话级可调**；`原文区下限` 滑块常驻显示。
- **折叠状态记忆**：**全局记忆**——按分组 id 存一份偏好（`user_overrides` 下 `ui.storySession.collapsedSections`），所有会话共享，无需迁移。

## 3. 各模块设计

### 3.1 滑块通用化（`CommitSlider` v2）

升级 `lib/core/widgets/commit_slider.dart`，新增：

1. **仅按住圆点拖动**：用 `Listener` 包裹内置 `Slider`，在 `PointerDownEvent` 判定落点是否落在圆点命中半径内，不在则吞掉指针，使 `Slider` 收不到 tap，屏蔽"点轨道跳值"。保留 `Slider` 原生语义与键盘可达性。若命中拦截在目标平台不可靠，退化为自绘 `CustomPaint` + `onHorizontalDragUpdate` 的极简滑块。
2. **数值可点按输入**：新增可选常驻数值显示，点按弹出数字输入对话框；抽出共享 `showNumericInputDialog`（统一现有 chat sheet 与 `IntermediateSliderField` 各自手写的版本）。

迁移范围（故事模式）：`IntermediateSliderField`、`IntermediateEffectiveContextLimitSlider`、`IntermediateRatioOverrideField`、`_SliderRow`、`_EffectiveContextLimitSlider`、`_DeferredSliderTile` 及上下文预算内部滑块。对话模式滑块本轮不动。

### 3.2 思考预算"未配置"

数据层已全程支持 `null`（drift 列 nullable、resolver `session ?? global ?? null`、`ThinkingParamBuilder` 把 `null → {}` 即"不发，用模型默认"）。仅 UI 3 处：

- `IntermediateReasoningEffortSelector`：`value` 改为 `ReasoningEffort?`，仿 `IntermediateReviewEnabledSelector`/全局 `_ReasoningEffortPicker` 增第 5 项。会话语义为**"跟随全局"**（null = 继承全局故事默认；"用模型默认"由全局再选"未配置"达成）。
- 调用处去掉 `?? ReasoningEffort.disabled` 兜底，透传 null，并加"当前生效：…"副标题。
- i18n：`sessionReasoningEffortOptions` 下加 `notSet`。

无 drift 迁移、无 resolver/adapter 改动。

### 3.3 上下文预算全部可调

- **数据层**：`chat_sessions` 新增 `compactionTriggerRatioOverride`（`RealColumn.nullable()`，NULL = 继承全局）；`schemaVersion` 33 → 34；`build_runner` 重生成。`ContextBudget.compactionTriggerRatio` 已在 `default_config.json`，全局走 `user_overrides` 键。
- **UI**：`ContextBudgetSlider` 新增 `onCompactionTriggerRatioChanged`，将 `_FixedSliderMark` 换为真 `CommitSlider`（范围 **0.30–0.80**，步长 0.01）；`原文区下限` 滑块常驻显示（保留"动态"为一个显式选项，但默认即给可拖滑块）。全局 `IntermediateContextBudgetSection` 与会话 sheet 均接入。
- **接线**：`ConfigurationResolver` + `IntermediateCompactionService` 消费会话覆盖值（沿用 `session ?? global`）。沿用现状不做跨字段强校验，仅 UI clamp。

### 3.4 会话设置重构（折叠分组 + 边界层次）

**两级视觉层次**：

- **分区（强边界）**：`CollapsibleSettingsSection`——填充/描边圆角卡 + 标题行（标题 + 展开箭头），分区之间留较大间距。
- **单项（弱边界）**：`SettingsTile`——分区内每个配置项为内嵌描边圆角瓦片，统一垂直节奏与对齐；同类内每项都有清晰边界，与分区卡形成层次。
- **标题栏**：`会话设置` 旁放**一键折叠 / 一键展开**。
- **常驻**：仅"查看记忆库"入口置顶（常驻，不参与折叠）；"重建向量索引"并入可折叠"记忆管理"组。
- **默认态**（仅首次生效，之后按全局记忆）：展开 `分步骤模型配置`、`提示词`；折叠 `生成参数`、`上下文窗口`、`上下文预算`、`工具调用(+审查)`、`推荐回复`、`记忆管理`。
- **持久化**：`user_overrides.ui.storySession.collapsedSections`（id 列表），全局共享。

### 3.5 事实层变更小窗（2026-08-13 新增）

本轮摘要小窗之后新增「事实层变更小窗」（`FactsChangePanel`），展示本轮事实层的新增/更新/追加/移除/别名/归档，让用户直观看到记忆库的变化（之前只能点开记忆库人工对比）。

- **数据链路**：summarizing 阶段产出 `FactsDelta`（LLM 意图），persisting 阶段 `FactApplier.applyDeltas` 应用后合成 `FactsChangeRecord`（含变更前/后）→ 持久化到 `intermediate_round_artifacts.facts_changes`（schema v35）→ UI 消费。
- **交互**：折叠行「事实已更新 · N 项」，展开逐条变更；点击单条弹 `FactsChangeDetailDialog`（动作徽章 + 实体·类型 + 属性 + 变更前/后 + 原因 + 置信度）。无变更时显示「本轮无事实变更」占位（区别于摘要小窗无数据即隐藏）。
- **挂载**：`intermediate_round_panels_builder`（当前轮 idle/生成中、历史轮）+ `intermediate_chat_body`（历史轮摘要小窗之后）。

### 3.6 记忆检索门槛设置（2026-08-13 恢复）

恢复宏摘要重构时随 `MacroSummaryConfig`/`IntermediateMemorySection` 容器删除而丢失的「向量化阈值」UI 入口（用户反馈：原版本有「评分大于 X 才向量化」设置，现找不到）。

- **组件**：`IntermediateVectorizeThresholdSection`，接入「工具与记忆」设置子页。
- **两个 1-5 分滑块**（`CommitSlider`）：存储索引门槛（`importance_storage_threshold`，默认 3）+ 向量化门槛（`micro_vectorize_threshold`，默认 4）。纳入低分（如 2 分）记忆需同时调低两个门槛。
- **底层不变**：两级向量化策略（DOC-10 §8）与阈值参数一直保留在 `retrieval` 组，仅补 UI 入口。附带补全 `settings_repository_impl._configToMap` 的 retrieval 节点（原仅序列化 6/16 字段，存在其他 override 时丢值的休眠 bug）。
- **会话级覆盖**：暂不做（避免 drift 迁移 + 5 处接线），留作后续。

### 3.7 记忆系统加固（2026-08-13 第二批）

针对用户反馈①②④的记忆系统加固（漏洞A修复 + 提示词优化）：

- **漏洞A（重复实体）修复**：`FactContextBuilder.buildKnownEntitiesBlock` 新增 `focusEntityIds` 参数，本轮 retrieving 阶段检索命中的低分实体（importance<baseThreshold）也注入【已知实体上下文】；`summarize_phase_handler` 从 `ctx.retrievedFacts` 取命中实体 ID 传入。修复"庄园 vs 异世界庄园"式重复（低分实体原本对更新步骤不可见，提示词去重规则失效）。代码层实体消歧（create_entity 前语义去重）视实际重复率再定。
- **提示词优化**（`intermediate_prompts_v2.dart`）：
  - 事实层：新增"职责分配/身份赋予/持久关系建立"提取场景（①积极性）；强化信息合并规则 + 工具 value 字段保真提示（①保真）
  - 事件摘要：新增【检索友好性】小节，引导为未来语义检索命中而写（④）
  - 关键词：来源改为"当前消息语义意图+近几轮语境推断检索目的"（历史补充语境非直接抽词），强化逆向匹配记忆库存储格式（④）

事实更新失真的彻底解决依赖模型能力，"推荐优秀模型+建议重试"作为产品方向后续考虑，不在本批代码。
