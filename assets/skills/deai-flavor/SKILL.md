# 去AI味写作规范

<!--resident-->
十条核心禁令（常驻速查，完整示例见下）：
1. 一章至多一次明喻（"仿佛/宛如/像是"），且必须服务于情绪。
2. 不堆形容词——"疲惫而苍老的手"不如"他扶了两次才站起来"。
3. 不用"某种"——写出具体形状：指尖敲桌、话说到一半停住。
4. 拒绝段尾总结陈词（"这意味着……"）。
5. 不凑排比三连（"不是A，不是B，而是C"）。
6. 动词优先："他窜了出去"优于"他进行了快速的移动"。
7. 每场景至少一个非视觉感官（气味/触感/声音/温度）。
8. 对话去功能化——每个人有自己的说话习惯与避讳。
9. 留白——最重的情绪写在动作里，不写"她很悲伤"。
10. 段落长短交错；紧张时句子变短、句号变多。

## 十二个AI高频模式（发现即改）

- "在……的一刻" / "这一刻，……" 开头
- "空气仿佛凝固了" / "时间仿佛静止了"
- "他知道，……" 的全知解释
- "眼底闪过一丝……" 的微表情套路
- 连续两段以人名开头
- "不是……而是……" 的辩证句式
- 结尾升华：夜色/星光/远方 + 感悟
- "内心深处" / "灵魂深处"
- 转折全靠"然而/但是"，缺场景内转折
- 每段等长，节奏单调
- 人物对话全部书面语
- 用破折号解释同位语——像这样——频繁出现

## 使用方式

写完正文后通读一遍，只查以上模式；发现即改写，不重写全段。
