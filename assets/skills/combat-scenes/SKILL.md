# 战斗场面写作

## 目标
让读者感到"疼"与"险"，而非招式说明书。

## 六条技法

1. **短句提速**：战斗中平均句长压到 15 字以内；段落 1-3 句。
2. **代价先行**：每次交锋留伤——擦伤、喘息、装备损耗；无伤的战斗无重量。
3. **空间锚点**：开打前确立地形（窄巷/断桥/火场），战斗中反复利用地形反转。
4. **感官轰炸**：痛感、血腥味、耳鸣、视野缺损；视觉之外的战场。
5. **胜负手只一个**：整场战斗只设计一次决定性转折，前置两次误导。
6. **人物性格入打法**：谨慎者借环境，狂怒者弃防御；打法即人物。

## 结构模板

试探（短）→ 交锋升级（互有损伤）→ 绝境 → 转折（地形/伏笔兑现）→ 收束（代价盘点）。

## 禁忌

- 不逐帧描写每个动作；略写次要交锋。
- 不用"快得看不清"偷懒——写看清了什么残影。
- 主角不允许永远赢；按大纲与骰子（跑团模式）决定结果。
