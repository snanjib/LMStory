# 世界书撰写规范

## 条目结构

每个世界书条目应包含：
- **主键**：触发词（人名/地名/组织名/物品名），含常用别名。
- **类别**：character / location / item / lore / organization。
- **正文**：客观、可验证的设定事实，不含剧情过程。
- **重要度**：1-5；≥4 的条目建议设为常驻（forceInject）。

## 写作守则

1. **事实句式**：写"魔法需要等价代价"，不写"传说中魔法或许需要代价"。
2. **条目原子化**：一条目一主题；"王都"与"王室"分开。
3. **不写剧情**：剧情进记忆库（record_event_memory），设定进世界书；世界书记录"龙讨厌银器"，不记录"第3轮主角用银器吓退了龙"。
4. **别名完备**：为主键收录简称、尊称、误称（检索命中率的关键）。
5. **冲突处理**：新设定与旧条目冲突时，不直接覆盖——先向导演说明差异，确认后更新并注明修订理由。
6. **节制常驻**：forceInject 只给主线必需条目（≤5 条），其余走检索。

## 与工具的配合

- 建条目：update_facts 的 create_entity 动作 + 属性写入；补别名用 update_facts 的 add_alias 动作。
- 查冲突：先 query_facts 同类条目。
- 升常驻：世界书条目对你是只读的，forceInject 只能向导演建议，由导演在资源库中修改；你无法直接变更。
