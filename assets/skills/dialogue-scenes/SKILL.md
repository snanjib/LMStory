# 对话场景写作

## 目标
对话推进关系与信息差，不是信息交换机。

## 五条技法

1. **潜台词优先**：人物说的≠想的。想拒绝时反问，想靠近时挑刺。
2. **每句对话必有反应**：沉默、岔开、动作，都算反应；不允许自说自话。
3. **信息差驱动**：读者知道的比人物多（或相反）时对话才有张力。
4. **打断与抢话**：真实对话有打断。在情绪高点让句子被截断。
5. **对话标签极简**：用动作代替"他说""她说"；只有必要时才标注说话人。

## 节奏模板

- 开场：以一个具体动作或环境声切入，不要"他开口说道"。
- 中段：三轮一小冲突，一句一变化；穿插两个非语言动作。
- 收束：以未说完的话或动作结束，不总结。

## 长度
对话场景正文 300-600 字为宜；除非导演要求，不写满。
