# LMStory brand assets

`lmstory_logo_v1.svg` is the first formal product logo adopted by the app.

- The three-node core represents the AI model as a thinking and associating engine.
- The open path represents the world continuing to form through the user's direction.
- `lmstory_logo_v1_dark.svg` is the light-on-dark UI variant.
- `lmstory_app_icon_v1.svg` is the regular icon artwork for platforms that do not apply their own icon mask.
- `lmstory_app_icon_v1_maskable.svg` is the full-bleed icon artwork for Android, iOS, and web install surfaces.
- `lmstory_android_foreground_v1.svg` is the transparent foreground artwork used by Android's adaptive icon resource.

Android API 26+ uses a native adaptive icon so the launcher owns the outer shape and does not wrap the icon in a second white legacy-icon plate. Older Android versions use the full-bleed artwork as the fallback. iOS and web install icons also use the full-bleed artwork so their system masks are not applied on top of an already-rounded transparent canvas.
